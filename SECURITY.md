# Security Policy

Use these templates only on systems and data you own or are explicitly
authorized to access. Never place secrets, personal records, confidential
instructions, or production credentials in a prompt pack or evaluation case.

The defensive red-team template intentionally avoids operational exploit and
safeguard-bypass payloads. Report a security concern privately to the
maintainer rather than adding a working exploit to an issue.

Agent workflows must default to read-only inspection. Consequential writes,
external communications, permission changes, deletion, and publication need
specific authority and a preview of the exact target and effect.
